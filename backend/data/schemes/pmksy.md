# Pradhan Mantri Krishi Sinchayee Yojana (PMKSY)
Source: https://pmksy.gov.in/

PMKSY aims to improve irrigation access and water-use efficiency. Its components and implementation are administered through the relevant central and state departments and may include micro-irrigation and watershed-related activities.

Farmers should check state-specific component availability, application periods, beneficiary contribution, technical standards and local implementing-agency guidance before applying. The platform must not promise that a subsidy is available for a particular farmer or location without a current official notification.

Official portal: https://pmksy.gov.in/

Evidence note: This local reference is an orientation summary. Verify current component details with the state agriculture or irrigation department.
